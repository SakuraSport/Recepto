# 📸 Скриншоты Recepto

## 1️⃣ Главная страница (01-homepage.png)
Главная страница приложения со светлой темой. Показывает:
- Навигацию с логотипом и кнопками
- Героический блок с приглашением
- Карточки популярных рецептов
- Кнопку переключения темы (луна)

## 2️⃣ Тёмная тема (02-dark-theme.png)
Та же главная страница, но в тёмной теме. Демонстрирует:
- Тёмный фон (#0d1117)
- Светлый текст для лучшей читаемости
- Плавный переход между темами
- Кнопка переключения теперь показывает солнце (☀️)

## 3️⃣ Поиск и фильтрация (03-search-recipes.png)
Страница `/recipes/` с функциями поиска:
- Поле ввода для поиска по названию, ингредиентам, описанию
- Кнопки фильтрации по категориям (Завтраки, Обеды, Ужины, Десерты, Напитки, Закуски)
- Список всех рецептов с карточками
- Количество рецептов и их информация (просмотры, лайки)

## 4️⃣ Профиль пользователя (04-user-profile.png)
Личный профиль пользователя, отображающий:
- Аватар пользователя (или emoji)
- Основную информацию (ник, количество рецептов, дату регистрации)
- Статистику (количество подписчиков, год входа)
- Список собственных рецептов
- Кнопки "Редактировать" и "Удалить" для администраторов
- Информацию о статусе (Администратор или Пользователь)

## 5️⃣ Админ-панель Django (05-admin-panel.png)
Встроенная Django админ-панель на `/admin/`, позволяющая:
- Управлять пользователями
- Редактировать и удалять рецепты
- Управлять категориями
- Просматривать статистику
- Управлять профилями пользователей

---

## 🎯 Что демонстрируют скриншоты

✅ **Функциональность:**
- Работающая главная страница с реальными рецептами
- Поиск и фильтрация работают корректно
- Профиль показывает рецепты пользователя
- Темизация переключается между светлой и тёмной

✅ **Дизайн:**
- Современный, чистый UI
- Красивые карточки рецептов
- Адаптивный и отзывчивый дизайн
- Плавные переходы и анимации

✅ **Возможности администратора:**
- Доступ к админ-панели
- Кнопки управления рецептами (видны только для администраторов)
